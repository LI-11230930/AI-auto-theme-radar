# 阅读与失败降级边界

能力报告来自本机最近最多100条档案，达到上限会说明可能还有。它是本地记录核对，不是本次登录、上游可用性或模型理解测试。字幕、ASR、OCR分别计数，同一视频可计入多个类别，不能把类别之和当作视频总数。

| 路径 | 当前取得/提供预算 | 失败与实际范围 |
| --- | --- | --- |
| 平台/浏览器字幕 | 标准P1每份5000字符；扩展实际前三P每份15000字符、5000字符分段；单模型任务总计50000字符 | 字幕轨缺失、空、失败分别记录；字幕取得不保证整片完整，已取得文字不代表模型已读 |
| 本地ASR | 仅P1无可读字幕时显式启用；最多处理前600秒、32MiB；下载30秒、转写180秒；最多1000段/40000字符 | 只有明确无轨/空轨可触发；鉴权/限制不强行回退；长视频需原有分段开关，源时长最多7200秒；空/过少文字留待恢复，机器结果可能误识 |
| 本地采样OCR | Windows.Media.Ocr；仅P1明确无轨且缺可读正文；源视频不超600秒/32MiB，下载30秒、工作进程240秒 | 画面采样间隔max(2,ceil(时长/100))秒，实际采样数另记；Python循环210秒、单帧OCR20秒，父进程仍受240秒总预算约束；不足80非空白字符留待恢复 |

OCR处理的是采样帧中的文字，不是平台字幕轨、完整画面识别或完整观看；ASR处理的是有界音频的机器转写。模型只收到归档文字，没有直接看画面或听音频。P2/P3不会启动媒体回退。

当前非模拟判断只有在主题/材料快照有效，引用当前视频文字，且记录了正的有效提供字符范围时才计入“分析”。零提供、模拟、过期材料、时间轴、简介、图片地址和弹幕不能冒充实际视频正文阅读。

所有路径继续受配置开关、来源身份、取消、大小、超时和正文质量门槛约束。没有配置、工具缺失、空文本或平台限制时保留缺口，不从标题补造正文，不因增加诊断统计而下载或执行任何内容。小红书仍按安装者的暂停设置处理；这些B站路径不能当作小红书能力验收。
