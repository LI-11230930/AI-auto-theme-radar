# v0.1.0-beta.33 已知限制

开发目标与反馈规则已经接入配置、阅读顺序和统一模型提示；推荐质量改善仍需在使用者自己的真实内容中持续验证，不代表模型会稳定理解所有偏好。重复反馈只保存线索，尚不自动合并相似内容。可选前三P和有界长字幕分段已实现；超过前三P和分P音视频回退仍属后续范围。统一轮次可显式开启有界灵感跟进，默认关闭，未关联或正文不足时不生成方案。本版新增按需灵感卡，由当前Agent读取明确关联的两来源归档，机制引用与开发建议分开；不能据此证明代码运行效果，详见[灵感卡指南](INSPIRATION.md)。

首版交付本地阅读、筛选、档案与邮件交接。beta.6增加本地统一调度：电脑和服务需运行，交互模式还需Agent持续在线；没有后台CLI的宿主不能被服务自动唤醒。beta.18补齐统一配置和显式加密凭据加载，但首次安装仍需自己的模型、账号与邮箱。以下不作为已完成能力：

- 小红书、云端独立B站登录和无人值守、多平台自动互动仍属后续范围。B站不发评论或@。
- 已验证环境以Windows为主。DSH、WorkBuddy、TRAE、Codex各有真实模型执行路径，Codex项目原生MCP统一轮次已生成草稿；各发行版后台与长期运行范围见[宿主兼容说明](HOST_COMPATIBILITY.md)。
- 作者投稿接口可能受限。扩展只取当前屏幕可见的最多20条，不滚动全量历史。安装者需要主动打开作者页。
- 持续模式一轮最多尝试9条视频，最多形成3条正文判断。字幕或ASR不是完整课程观看，无法读取画面中的图表、代码或全部硬字幕。Windows可选画面回退仅在字幕和语音无正文时使用，默认关闭；采样帧不代表完整视频或全部硬字幕。
- 扩展阅读只取实际前三P，每份视频正文最多15000字符、同一任务总材料最多50000字符；按5000字符分段不是逐段独立总结，也不保证读取全部字幕。语音和采样画面仍只回退P1，不补读其他分P媒体。
- ASR单次最多处理10分钟、32MiB、180秒；显式启用长视频分段时保留实际源时长，只读前10分钟。专有名词、数字和否定可能误识别。正文字符门槛只限制信息量，不证明识别质量。新闻事实由视频转述，模型不自动核验所有外部说法。
- 榜单用途图依据原简介或最多4000字符README摘录概括，非仓库代码运行图。确实没有资料的榜单条目保留链接与Star，明确暂无简介且不生成流程；不因该项缺失中断其他条目。
- GitHub搜索有预算、资料为取得时快照，不穷尽所有仓库。统一流程允许对API返回的部分搜索结果完成有界阅读与投递，同时保留搜索不完整标记，不推进该主题覆盖窗口；旧单平台严格模式保持不变。Trending是GitHub展示榜单，不宣称独立计算全站Star排名。鉴权、限流、网络失败以及必需正文或模型结果缺失仍阻止投递。
- 邮箱连接不随代码提供。旧单平台网页/CLI阅读仅生成草稿；统一计划明确启用SMTP后可自动投递；Agent邮箱工具和SMTP是不同通道。发信失败或结果未知需要核对，不能盲目重试。
- 本地账本不自动跨电脑同步。模型阅读轨迹和宿主名称是调用报告，不是独立身份或语义理解证明。

问题反馈请给出版本、操作步骤与脱敏报错。不要上传config.local.json、.data、Cookie、模型补丁、令牌或邮件正文。

Windows加密凭据绑定当前系统用户，复制该文件到其他账号或系统不能直接使用；其他系统可使用环境变量。自动唤醒记录是配置报告，不证明未来执行或长期稳定性。Web状态检查不连接宿主邮箱验证身份。

日志过滤仅覆盖已知敏感字段和常见凭据文本形式，不保证识别任意自由文本中的隐私或新型密钥。历史日志不会因升级自动清理，分享诊断资料前需自己检查；不要上传整个数据库。

邮件反馈入口只在同一台电脑的本地服务运行时可用；不提供云端中转或远程反馈。点击/预取不保存反馈，预览会新增本地反馈记录但不改主题，明确应用后才调整偏好。旧邮件和已不存在主题不能自动迁移到其他主题。

POSIX进程组终止有1秒TERM到KILL升级；仅覆盖Runner自己创建且未脱离该组的子进程。主动创建新会话/进程组、Windows父进程先退出留下的独立后代或整个系统强制断电不在此保证中。Windows进程树取消已单独测试，不将跳过的POSIX用例算作本机通过。

备份结构核验以当前版本V2的字段、键、外键及索引属性为准，不能代替对任意外来数据库或所有自定义CHECK表达式的审计。仍仅支持SQLite备份/隔离演练，不包含配置、登录、模型和媒体文件，也不自动替换正式库。
