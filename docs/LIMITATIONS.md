# v0.1.0-beta.2 已知限制

首版交付本地阅读、筛选、档案与邮件交接。以下不作为已完成能力：

- 小红书、云端独立B站登录和无人值守、多平台自动互动仍属后续范围。B站不发评论或@。
- 已验证环境以Windows为主。DSH项目web入口及一次兴趣轮次、WorkBuddy交互提交、TRAE查询复用各有实测；不能据此推断所有版本的四宿主完整兼容。Codex片段需要核对本机发行版。
- 作者投稿接口可能受限。扩展只取当前屏幕可见的最多20条，不滚动全量历史。安装者需要主动打开作者页。
- 一轮兴趣阅读最多3条视频P1。字幕或ASR不是完整课程观看，无法读取画面中的图表、代码或全部硬字幕。OCR仍为可选实验工具，不是默认阅读链。
- ASR最多10分钟、32MiB、180秒；专有名词、数字和否定可能误识别。正文字符门槛只限制信息量，不证明识别质量。新闻事实由视频转述，模型不自动核验所有外部说法。
- GitHub搜索有预算、资料为取得时快照，不穷尽所有仓库。Trending是GitHub展示榜单，不宣称独立计算全站Star排名。页面改变、403/412/429或网络失败会中止。
- 邮箱连接不随代码提供。网页/CLI阅读没有自动发信；Agent邮箱工具和SMTP是不同通道。发信失败或结果未知需要核对，不能盲目重试。
- 本地账本不自动跨电脑同步。模型阅读轨迹和宿主名称是调用报告，不是独立身份或语义理解证明。

问题反馈请给出版本、操作步骤与脱敏报错。不要上传config.local.json、.data、Cookie、模型补丁、令牌或邮件正文。
