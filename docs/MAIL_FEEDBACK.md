# 邮件精选反馈

在工作台“邮件内容”勾选“邮件精选显示反馈入口”并保存。默认关闭；只影响新草稿，不启用邮件发送或调度。

GitHub主题项目和B站精选的两个链接携带原条目ID、原主题ID和反馈意向。日周榜条目未绑定主题阅读判断时不附入口；同项目去重后按实际选用的主题绑定。

1. 在同一台电脑打开邮件里的“有用”或“不感兴趣”。本地主题雷达服务需要运行。
2. 页面预填条目、主题和反馈类型，点击或邮件软件预取不会保存反馈、改主题。
3. 填写一个优先词或排除词，点击“保存反馈并预览”。这会保存一条本地反馈记录，主题尚未改变。
4. 核对原规则和应用后的规则，再点击“应用以上规则”。有用添加优先偏好；不感兴趣添加字面排除词。规则作用于该主题的各平台，请用具体词，避免过宽。
5. 可在反馈记录中撤销。若主题后来已被修改，版本保护会拒绝覆盖，请先核对差异。

手机、另一台电脑的localhost指向各自设备，不能连接原电脑。没有云端中转。原主题删除、停用或更换平台时不会悄悄选中其他主题；可自行选择合适主题后重新预览。

高级模板对应：`feedback: {"enabled": true, "baseUrl": "http://127.0.0.1:8767"}`。baseUrl仅允许本机HTTP根地址与1024以上端口；首页保存会使用当前页面地址。链接不携带密钥或CSRF令牌；应用仍需本机同源POST与当前版本校验。原模板缺字段按关闭处理。
