# 由使用者设置的内容

首次启动不预置主题、UP主、账号、邮箱或邮件授权。网页创建主题后才可采集。模型、B站登录、邮箱连接与可选ASR均使用安装者自己的配置。

## 主题与可推送内容

在主题设置填写名称、兴趣描述、关键词、排除词与平台。B站可选不限UP兴趣推荐、关键词搜索或按作者UID过滤；停用主题就不参与之后的采集。GitHub仓库按自己的主题筛选，不自动导入开发者主题。

可选填写“开发目标”，例如“开发一个能断点恢复的本地资料整理插件”，再选择是否优先具体实现。搜索仍使用关键词；目标交给所选Agent判断材料对你的用途。目标和偏好按主题保存，修改后旧判断保留为历史，下轮按新主题版本判断。

“优先偏好”最多20个短语，仅在既定候选及阅读预算内调整顺序，并提供给模型；不会额外搜索、绕过排除词或凭标题入选。B站的偏好加权需先命中原关键词，GitHub保留既有探索名额。

在内容档案对条目反馈，选择“有用 · 优先此类”并填写希望优先的机制短语，先预览，再点击应用；减少此类/不相关对应字面排除词。重复只记录线索。应用和撤销均保留记录；若主题后来修改，旧预览或撤销不会覆盖新设置。旧版本中仅记录的“有用”意见需要重新预览，升级不会自动应用。

需要批量导入时，在theme-radar-app目录运行 node tools/import-topics.ts <自己的JSON文件>，文件可以是一个主题或主题列表。主题结构以网页保存后的本地配置为参考。新增可选字段示例：

```json
{
  "goal": {"objective": "开发本地资料整理插件", "implementationFirst": true},
  "preferred": ["本地运行", "失败恢复"]
}
```

## B站阅读深度

每个主题可选 `videoReading: "standard"`（默认）或 `"extended"`。简单和高级主题编辑器均提供此选项。标准只读P1，每份正文最多5000字符；扩展读实际存在的前三P，每份最多15000字符，按连续5000字符分段提供，同一模型任务的材料总量仍有50000字符上限。档案记录实际提供范围；缺轨或读取失败不会冒充已读。

更改深度会更新主题版本，旧判断保留为历史；只有P1的旧缓存不能满足扩展模式。扩展可能增加平台请求和模型输入量。语音与画面回退仍仅用于P1并遵守原开关与预算，文本分段不延长媒体处理时间。

## 邮件模板

网页“自定义邮件内容与模板”提供可编辑JSON，保存到本地.data/mail-template.json。也可复制mail-template.example.json到该位置后修改。保存不会启用投递。

| 字段 | 作用 |
| --- | --- |
| github.sections | 从projects、daily、weekly中选取并排列栏目；可只选主题项目或只选周榜 |
| github.subject | GitHub邮件标题，支持{date}与{slot} |
| github.titles | 各栏目的显示标题 |
| github.entry | 每个项目的条目格式 |
| bilibili.subject/title/entry | 视频邮件的标题、正文标题与条目格式 |
| footer | 自己的纯文本页脚，可留空 |

条目支持{index}、{title}、{url}、{summary}和{flow}；GitHub另支持{stars}。可以删掉Star或流程、改变顺序和换行，但必须保留{url}与{summary}。例如只保留链接和简介：

```json
{
  "github": {
    "sections": ["projects"],
    "subject": "我的项目周刊 {date}",
    "entry": "{title}\n{url}\n{summary}"
  },
  "bilibili": {
    "title": "今日视频",
    "entry": "{title}\n{url}\n{summary}"
  },
  "footer": ""
}
```

模板字段为文本，不执行HTML、脚本或任意表达式。已冻结草稿使用生成时的模板；修改模板只作用于新草稿，不改写历史或自动重发。

## 邮件与预算

收件人、发件账户和SMTP在自己的config.local.json中设置；Agent邮箱使用自己的连接和明确启用的本地政策。默认发送关闭。可在配置中降低候选与精选预算；单轮视频和邮件有界上限用于控制费用与重复投递，模板不能绕过发送次数或授权。

09:00/18:00及Asia/Shanghai仍为当前批次规则，本版未提供任意时区/时段调度器。自定义模板不等于新增定时任务。

## 开发灵感

按自己的主题和开发目标生成视频—仓库灵感卡，选择当前Agent执行。卡片建议、来源和字符范围独立于邮件模板，不自动改变主题、平台开关或投递。见[灵感卡指南](INSPIRATION.md)。

首页可选“从B站精选整理开发灵感”；高级统一计划可调整卡片及仓库补读预算。此设置默认关闭，保存只更新配置，实际运行仍需所选Agent参与。
