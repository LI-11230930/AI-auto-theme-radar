# 可选浏览器字幕批次

优先使用平台字幕或本地ASR。需要从可见页面采集时，在Chrome加载旁边browser-extension目录，版本0.3.2。详细权限和操作见 ../browser-extension/README.md。

在验证台选择1至3条已核对作者的视频创建临时配对码；在B站视频页打开扩展批次入口，授权本机8767服务后配对。每条先准备中文字幕，实际显示后确认开始，再观察完成后导入。相同BV/P1不重新导航；换页、换分P、断开或到期即停止。

只记录DOM显示过的字幕，不表示完整原字幕轨或画面理解；不读Cookie和评论，不发信。作者页可直接点击“交给本地验证台”导入当前可见投稿链接，无需字幕配对。
