## 权限与范围

- 基础权限仍只有 `activeTab`、`scripting`，点击扩展后才控制该次授权的标签页。
- 新增可选来源 `http://127.0.0.1:8767/*`，仅点击“授权本机访问并配对”时申请。拒绝可选授权仍可手动导出。
- 没有后台服务、常驻网页脚本、Cookie、历史、存储、下载API、调试器或B站全站权限。
- 不读评论、弹幕、音视频文件或Cookie，不调用字幕接口。B站内容脚本不连接本地服务；只有扩展批次页向固定本机端点提交JSON。
- 配对码与令牌只在批次页内存中，不传给B站内容脚本、URL、存储或日志。关闭或刷新批次页不能恢复。
- 只复用点击扩展时的 `www.bilibili.com` 视频标签页，同源依次导航；跨到作者空间或其他站点即停止。

## 更新

在 `chrome://extensions` 找到本项目扩展，点击重新加载，核对版本 `0.3.2`。升级时关闭旧批次页，视频页手动刷新一次以清除旧内容脚本，重新开启CC；新批次不会为了连接同一视频再次刷新。首次安装选择 本源码包旁边的 `browser-extension` 目录。这是本项目采集扩展，不是Codex浏览器控制扩展，不影响原GPT扩展。

## 有界字幕批次

1. 启动本地验证台 `http://127.0.0.1:8767/`。在浏览器批次区域选择已归档、实际作者UID与订阅一致、当前缺字幕的视频。每批1至3条，仅P1、每条不超过15分钟、总时长不超过1000秒。
2. 在已登录Chrome的B站视频页手动启用中文字幕，点击扩展 → “打开有界字幕批次”。新页只携带原标签ID。原页若有手动记录，先停止并导出；批次会导航并替换该页。
3. 在验证台创建配对码，2分钟内填入扩展页，点击“授权本机访问并配对”，核对Chrome提示的本机范围。
4. 核对清单，点击“连接视频并准备字幕”。当前已是同BV/P1时直接使用现有页面；只有换到另一条视频才导航。每条准备期最多90秒，你可手动开启CC、播放到实际字幕出现，再回批次页点击“字幕已显示，开始本条”。确认前不改变静音、播放位置，也不记录字幕。
5. 确认后才从头静音记录。保持两个标签页打开，不拖动进度、不切分P、不过久暂停。每条须实际结束、至少有一段字幕且未截断才请求导入；任何失败停止整个批次，不自动重试下一条。仅播放器元数据状态或同BV跟踪参数变化不再中断；实际换BV/分P、刷新文档或控制Port断开会停止。
6. 在验证台核对导入结果。只产生浏览器观察，不自动调用模型，不发邮件、评论或创建定时任务。

授权最长20分钟，绑定扩展来源、主题版本和指定视频材料版本。撤销、到期、订阅改变、服务重启或材料被其他宿主更新后停止。关闭批次页会断开控制；连接断开或10秒未收到心跳时，内容脚本停止自有记录和该批次启动的播放。已导入观察保留。电脑或浏览器冻结时，清理只能在恢复执行后完成。

“停止并撤销本次授权”先停止页面控制，再请求本地撤销。撤销或上传未得到确认时，先在验证台核对状态，勿把超时当作未导入。

## 手动JSON导出

- 视频页：开启字幕 → 扩展“开始记录” → 正常播放 → 结束后“导出JSON”。关闭弹窗不停止手动采集；拖动或换页会停止并保留部分范围。
- 作者页：在 `https://space.bilibili.com/UID/upload/video` 显示投稿后打开扩展并导出，仅包含当前可见最多20条链接，不自动滚动，不证明完整投稿或作者身份。
- JSON在验证台导入，原文和范围保留；视频作者由服务端另核对。

AI字幕误识别保留原样。即使从头播放至结束，也只能记录该次DOM显示范围，不能证明原始字幕轨完整、语音正确性或整片视听理解。字幕与模型判断分别存档。

关闭视频页清除该页内存，关闭批次页清除凭据。移除扩展或撤销Chrome本机可选访问权限停止后续连接，不删除已导出的JSON或现有档案。
